API Reference

Use the Sinyx API to cleanly extract public web content into Markdown, plain text, cleaned HTML, or semantic chunks for LLM and RAG pipelines.

Authentication

The API is syndicated through RapidAPI. To authenticate, pass your RapidAPI key and host headers with each request.

Extraction Endpoint

POST
https://sinyx.p.rapidapi.com/v1/extract

Request Body Details

Parameter (JSON) Type Required Description
url String Yes The public HTTP or HTTPS URL to extract. For batching, use /v1/extract/batch with urls.
selector String No A CSS selector to precision-target specific DOM content (e.g. .article-body).
format String No Output format. Options: markdown, text, html, full, chunks. Default: full.

Code Example: Single URL (cURL)

curl --request POST \
  --url https://sinyx.p.rapidapi.com/v1/extract/batch \
  --header 'Content-Type: application/json' \
  --header 'x-rapidapi-host: sinyx.p.rapidapi.com' \
  --header 'x-rapidapi-key: YOUR_KEY' \
  --data '{
    "url": "https://sinyx.me",
    "format": "markdown"
}'

Code Example: Batch Processing (cURL)

Extract up to 5 URLs in parallel. If one fails, the others still succeed.

curl --request POST \
  --url https://sinyx.p.rapidapi.com/v1/extract \
  --header 'Content-Type: application/json' \
  --header 'x-rapidapi-host: sinyx.p.rapidapi.com' \
  --header 'x-rapidapi-key: YOUR_KEY' \
  --data '{
    "urls": ["https://apple.com", "https://github.com"],
    "format": "markdown"
}'

Code Example: Batch Processing (Python)

import requests

url = "https://sinyx.p.rapidapi.com/v1/extract/batch"
payload = { 
    "urls": [
        "https://apple.com",
        "https://github.com"
    ],
    "format": "markdown"
}
headers = {
    "x-rapidapi-key": "YOUR_KEY",
    "x-rapidapi-host": "sinyx.p.rapidapi.com",
    "Content-Type": "application/json"
}

response = requests.post(url, json=payload, headers=headers)
print(response.json())

RAG Chunks Format

Set format: "chunks" to receive semantically segmented content with heading breadcrumbs and priority scoring. Each chunk is a self-contained block ready for vector database ingestion.

Field Type Description
chunkIndex Number Sequential index (0, 1, 2...) for ordering chunks.
headingPath String Hierarchical breadcrumb of the chunk's position, e.g. Root > Setup > Installation.
headingLevel Number The heading depth (2 = H2, 3 = H3, etc.). Root-level content is 0.
content String The extracted plain-text content of this chunk.
charCount Number Character count of the content.
priority Number Relevance score from 0.0 (noise, e.g. footer) to 1.0 (high-value, e.g. definitions). Use this to filter or sort chunks before sending to your LLM.

Code Example: RAG Chunks (Python)

Extract semantically chunked content and filter by priority for your RAG pipeline.

import requests

url = "https://sinyx.p.rapidapi.com/v1/extract"
payload = { 
    "url": "https://en.wikipedia.org/wiki/Artificial_intelligence",
    "format": "chunks"
}
headers = {
    "x-rapidapi-key": "YOUR_KEY",
    "x-rapidapi-host": "sinyx.p.rapidapi.com",
    "Content-Type": "application/json"
}

response = requests.post(url, json=payload, headers=headers)
data = response.json()

# Filter high-value chunks for your vector DB
high_value = [c for c in data["chunks"] if c["priority"] >= 0.6]

for chunk in high_value:
    print(f"{chunk['headingPath']} → {chunk['content'][:80]}...")
