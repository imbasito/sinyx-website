🎯 Precision Targeting

Need exactly one specific article section? Pass a CSS selector and Sinyx will extract only that block, ignoring the rest of the DOM.

curl --request POST \
  --url https://api.sinyx.me/v1/extract \
  --header 'Content-Type: application/json' \
  --header 'x-sinyx-origin-key: YOUR_API_KEY' \
  --data '{
  "url": "https://en.wikipedia.org/wiki/API",
  "format": "full",
  "selector": "main"
}'
